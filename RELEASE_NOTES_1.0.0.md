# Eaton UPS Card 1.0.0

Erste Version der eigenständigen Home-Assistant-Dashboard-Card für die Eaton 3S 850.

## Highlights

- Eigenständige Custom Card ohne Bubble Card
- Responsive Darstellung für Sections und Full Width
- Große 2×2-Messwertanzeigen
- Automatische NUT-Statusauswertung
- Integriertes Eaton-3S-850-Bild
- Grafischer Editor
- HACS-kompatible Repository-Struktur
